## 已完成的静态核查（别重做）

同步链路是：`Settings` 全局（`ui/components/settings_modal.slint` 第 8 行 `export global Settings`）
的 callback → Rust `src/gui/mod.rs` 的 `sbind!(on_set_bool/on_set_string/on_action, ...)`（约 1546 行起）
→ `set_setting_bool()` / `set_setting_string()`（约 1003 行）→ `core.update_settings()`。

**已确认静态上全部接齐，无缺口：**

- 17 个 bool 键：`launch_on_startup` / `hide_on_blur` / `double_click_launch` /
  `gpu_blur` / `rim_light` / `hotkeys_master_enabled` / `incremental_index` / `content_index_enabled` /
  `include_hidden` / `exclude_build_caches` / `clipboard_enabled` / `clipboard_dedupe` /
  `clipboard_ignore_password_managers` / `clipboard_mask_sensitive` / `ai_enabled` / `ai_lazy_load` /
  `ai_intent_parsing` —— 在 `set_setting_bool` 的 match 里**全部有分支**。
  （原为 18 个：`minimize_to_tray` 已于 2026-09-24 裁决移除，见
  `doc/实施进展与已知问题.md` 第 7 节「顺带发现 → 已裁决移除」。）
- 5 个 string 键：`theme` / `acrylic_opacity` / `default_mode` / `index_roots` / `clipboard_limit` —— 全部有分支。
- 6 个 action：`clear-cache` / `rebuild-index` / `clear-clipboard` / `save-hotkey` / `cancel-hotkey` /
  `browse-target` —— 全部有分支（在 `sbind!(on_action, ...)` 里）。
- 回写方向 `sync_settings_to_ui()`（约 830 行）覆盖了全部 22 个属性，**无遗漏**。

所以问题不在"有没有接上"，而在**运行时是否真的成立**。

## 要查什么

1. **逐项往返**：每个开关改一下 → 看 `config.json` 是否立即落盘 → 重启程序 → 看 UI 是否还是那个值。
   建议用 Python 读 `config.json` 做前后对比，别靠肉眼。
2. **有副作用的开关**：改完是否**真的生效**，而不只是存了个值。
   重点怀疑对象：
   - `gpu_blur` / `rim_light` / `acrylic_opacity` —— 改完要不要重新应用窗口材质？有没有立即生效？
   - `theme` —— 切换后界面是否立即重绘？
   - `content_index_enabled` / `include_hidden` / `exclude_build_caches` —— 代码里会触发 `reindex`，
     验证重建是否真的发生、有没有进度反馈、会不会卡界面。
   - `clipboard_enabled` —— 关掉后剪贴板监听是否真的停。
   - `launch_on_startup` —— 是否真的写了注册表 / 启动项。
   - `hotkeys_master_enabled` —— 关掉后全局热键是否真的失效。
3. **string 输入的健壮性**：`clipboard_limit`（数字）和 `index_roots`（路径列表，`;` 分隔）
   是自由文本。试试空串、非数字、不存在的路径、超长输入——会不会崩、会不会静默存进脏值。
4. **无反馈的控件**：哪些开关点下去**没有任何 toast 或视觉变化**？用户会以为没生效。
   现有代码里 `hotkeys_master_enabled` 有 toast，其他大多数没有——判断哪些**应该**有。
5. **`browse-target` 的原生文件对话框**：代码里有 `suppress_blur` 开关来防止失焦隐藏。
   验证这个保护真的有效（打开对话框时窗口不会消失），以及选完路径后
   `force_foreground` 是否把窗口正确拉回来。
6. **快捷键录制**（`hotkey-record` / `save-hotkey` / `cancel-hotkey`）：
   录制态、Esc 取消、重复组合键冲突检测，是否都正常。
