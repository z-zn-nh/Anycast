## 1. 项目与架构全景定位

本项目是一款面向 Windows 的 **Local-first Search & Action Platform（本地优先搜索与操作平台）**。前端研发的核心任务是以本项目已验证闭环的 HTML5/CSS3 原型为 1:1 蓝本，使用 Slint 原生声明式 DSL 与 Rust 强类型绑定，交付高品质、轻量级、低功耗、零闪烁的桌面级启动器界面。

## 2. 视觉体系与物理材质规范 (Windows 11 Fluent Acrylic)

### 2.1 物理穿透与毛玻璃材质
在 Windows 11 下，Slint 窗口的亚克力效果通过底层 Windows DWM API 与 Slint UI 上层微晶渲染配合达成：

1. **操作系统级透明穿透**：
   - 宿主窗口初始化时调用 `DwmSetWindowAttribute`：
     - `DWMWA_SYSTEMBACKDROP_TYPE = DWMSBT_TRANSIENTWINDOW` (3) 或 `DWMSBT_ACRYLIC` (4)；
     - `DWMWA_USE_IMMERSIVE_DARK_MODE = TRUE`；
   - 窗口呈现系统原生亚克力漫反射光影，壁纸色彩自然渗入。
2. **Slint 材质层叠 Token**：
   - **主窗口基底**：`rgba(20, 23, 31, 0.72)` + 1px 外边框 `rgba(255, 255, 255, 0.12)`；
   - **上沿晶莹高光 (Rim Light)**：`inset 0 1px 0 rgba(255, 255, 255, 0.22)`；
   - **微晶浮层/卡片**：`rgba(255, 255, 255, 0.038)`，内阴影 `inset 0 1px 0 rgba(255, 255, 255, 0.08)`；
   - **严禁生硬色块**：杜绝使用 95% 以上不透明死黑底，杜绝非项目原生硬编码亮蓝（`#0078d4`），所有交互反馈一律使用纯白与半透明微晶色阶。

### 2.2 严格对齐基准线 (16px Grid)
- 全局主窗口内部边距严格以 **`16px`** 为左基准线：
  - 搜索栏文字输入光标与图标；
  - 置顶展架卡片起始左边缘；
  - 分类栏“全部”标签文字；
  - 搜索结果列表项图标与文字；
  - 底部状态提示条；
- 形成绝对齐整的视觉秩序，严防左右参差不齐。

## 3. 窗口尺寸体系与全向拖拽缩放引擎

### 3.1 尺寸规范
- **默认/推荐黄金规格**：`860px (宽) × 560px (高)`（设计原型最佳可视比例）；
- **尺寸约束范围**：
  - 宽度：`720px ~ 96vw`；
  - 高度：`480px ~ 94vh`；
- **自适应与防截断**：
  - 窗口尺寸变更时，卡片展架自适应排布，结果列表垂直自适应拉伸，绝不允许底部文字或卡片产生生硬切边。

### 3.2 边缘抓手与手动缩放
1. **缩放热区规划**：
   - **东侧手柄 (`resize-handle-e`)**：右边缘 8px 区域，光标变为 `ew-resize`；
   - **南侧手柄 (`resize-handle-s`)**：底边缘 8px 区域，光标变为 `ns-resize`；
   - **东南角抓手 (`resize-handle-se`)**：右下角 18×18px 点状矩阵抓手，光标变为 `nwse-resize`；
2. **尺寸持久化**：
   - 用户拖拽松开后，将宽高存入本地配置数据库（SQLite `user_settings` 表）；
   - 双击右下角抓手或点击恢复推荐尺寸按钮，平滑复位至 `860×560px`。

## 4. 核心功能视图组件研发规格

### 4.1 搜索输入栏与筛选触发器 (`SearchBar`)
- **左侧输入主体**：
  - 16px 矢量轻量放大镜图标；
  - 占位符提示：`搜索应用、文件、工程、剪贴板、快捷指令 (Tab切换模式)`；
  - 按下 <kbd>Tab</kbd> 即时切换“⚡ 极速模式”与“✦ AI智能模式”，模式胶囊平滑变色；
- **右侧极简微晶筛选按钮 (`FilterTriggerBtn`)**：
  - **无边框、无底色**（`background: transparent !important`）；
  - **纯图标形态切换**：
    - 收起/未过滤态：展示优雅纤细的空心漏斗（`Outline Funnel`）；
    - 展开/激活过滤态：即时切换为高亮纯白实心漏斗（`Solid Funnel`），杜绝任何灰色底色方块。

### 4.2 内联微晶多维检索抽屉 (`SearchFilterShelf`)
- **平滑展开折叠**：
  - 赋予与筛选栏 100% 一致的缓动曲线：`0.22s cubic-bezier(0.16, 1, 0.3, 1)`；
  - 折叠时内容透明度提前淡出（`0.18s`），收拢时内边距同步归零，绝无卡顿；
- **三大维度微晶胶囊**：
  1. **时间维度 (`time-dropdown`)**：
     - 全部、今天、近3天、本周、本月、自定义范围；
     - 展开内置 **Windows 11 带起止范围的 Fluent 日历选择器**：双点击选择起始与终止日期，区间半透色带预览，底部“确定”执行过滤；
  2. **类型维度 (`type-dropdown`)**：
     - 应用 (EXE/LNK)、文档 (MD/DOCX/PDF)、代码 (RS/JS/TS/PY)、图片 (PNG/JPG/WEBP)、音视频、压缩包；
  3. **位置维度 (`location-dropdown`)**：
     - 支持内置常见磁盘路径、工程目录，支持即时路径过滤输入框与进入子文件夹查找；
- **选定反馈与重置**：
  - 胶囊激活时呈现高亮并带有小叉号 `×`（支持单项清除），右侧动态出现“重置”按钮。

### 4.3 置顶快速访问展架 (`PinnedShelf`)
- **固定卡片规格**：
  - 卡片宽度固定为 `86px`（严禁横向拉伸变形），内容居中展示 34×34px Squircle 应用/文件图标、单行截断标题与极简文件类型小徽标；
  - 悬停时右上角原地平滑浮现轻量取消置顶按钮；
- **横向鼠标滚轮专属切换**：
  - 鼠标悬停在置顶区域时，滚轮滑动精准转换为卡片横向平滑轮播；移出该区域后恢复列表垂直滚动；
- **0 抖动刚性收缩折叠**：
  - 外层容器锁定 `padding: 4px 16px; height: 20px;`，折叠按钮在光标正下方**绝对 0 像素位移**；
  - 轨道内部应用 `0.22s cubic-bezier(0.16, 1, 0.3, 1)` 抽屉收拢动效；
  - 折叠按钮无底色，展开显示 `⌃`，折叠显示 `⌄`。

### 4.4 分类切换分段栏与搜索结果列表 (`CategoryBar` & `ResultList`)
- **分类标签**：`全部`、`应用`、`文件`、`文件夹`、`剪贴板`；
- **空闲与搜索互通机制**：
  - 搜索框为空：直接渲染“🕒 最近使用”，按使用频率与加权自动排序；
  - 搜索框有输入：实时渲染“🔍 搜索结果”或“✦ 智能匹配”，按匹配度加权排序；
- **双击执行交互**：
  - 列表项或置顶卡片上双击时，触发轻微触感回弹动画（`scale(0.985) → scale(1)`），并即刻调用系统程序启动。

### 4.5 右键上下文菜单 (`ContextMenu`)
- **亚克力悬浮质感**：
  - `linear-gradient(180deg, rgba(255, 255, 255, 0.08) 0%, rgba(255, 255, 255, 0.02) 100%), rgba(18, 22, 32, 0.70)`；
  - 36px 模糊、190% 饱和度、顶部 1px 晶莹高光线；
- **菜单动作槽位**：
  - `↵ 打开 / 执行`（默认主动作）；
  - `📁 在文件资源管理器中定位 (Ctrl+O)`；
  - `📋 复制完整路径 (Ctrl+C)`；
  - `📌 固定到置顶 / 取消置顶 (Ctrl+P)`；
  - `📂 进入此文件夹查找 (Tab)`（仅对文件夹类型显示）；
  - `🗑️ 从最近记录中移除 (Del)`（危险警示项）。

## 5. 快捷直达系统（App与文件专属热键绑定）研发规格

### 5.1 功能定位与设计规范
用户可为任意常用应用程序（`.exe`）、工程目录或特定文件分配专属全局快捷键（如 `Alt+C`、`Alt+T`、`Alt+D`），**在系统任意窗口下直接按下即可直接调起或激活窗口，无需唤醒搜索框**。

### 5.2 设置面板组件规格 (`SettingsPanel` - Hotkeys Tab)
1. **纯双栏布局**：
   - 窗体为 `740×540px` 双栏贯通格局，右上角配备 `28×28px` 悬浮关闭叉号按钮（`#closeSettingsBtn`）；
2. **快捷直达卡片槽 (`HotkeyBindingCard`)**：
   - 左侧展示 32×32px 扁平微质感 Squircle 应用图标、应用名称与目标磁盘路径；
   - 右侧排列 **3D 机械质感键帽 (`.hotkey-badge`)**：
     - 具象化下沿边框（`border-bottom: 2px solid rgba(255, 255, 255, 0.28)`）与按键阴影；
     - 点击键帽即进入脉冲录制状态（红光呼吸动效 `pulseRecording 1.2s`），用户在物理键盘上直接按下组合键即完成录制；
   - **WinUI 3 开关**：独立控制该项热键启用/禁用；
   - **极简幽灵按钮**：
     - `▶` 测试运行（触发 `trigger_action` 并弹出就绪 Toast）；
     - `🗑️` 移除绑定；
3. **“+ 添加绑定”弹窗与表单**：
   - 单行按钮防折行设计，支持从最近使用快速选取条目，或通过 Windows 原生文件选择器浏览选定路径；
   - 包含防冲突建议提示卡片（推荐使用 `Alt + [字母]` 或 `Ctrl + Shift + [字母]`）。

## 7. 交互手感与动画参数基准

所有 Slint 动画必须严格对齐原型中的物理常数，杜绝任何生硬与拖沓：

| 动效场景 | 持续时间 (Duration) | 缓动物理曲线 (Easing) | 属性说明 |
| :--- | :--- | :--- | :--- |
| **筛选抽屉展开/折叠** | `220ms` | `cubic-bezier(0.16, 1, 0.3, 1)` | `max-height`, `padding`, `margin` 同步 |
| **筛选抽屉透明度** | `180ms` | `cubic-bezier(0.16, 1, 0.3, 1)` | 收起时提早淡出，滑落时柔和显现 |
| **置顶卡片展架抽屉** | `220ms` | `cubic-bezier(0.16, 1, 0.3, 1)` | 卡片轨道展开收起，与筛选栏完全同频 |
| **置顶折叠图标切换** | `0ms`（即时） | 物理即时切变 | ⌃ 与 ⌄ 瞬间切换，无旋转变形 |
| **双击条目触感微弹** | `150ms` | `cubic-bezier(0.34, 1.56, 0.64, 1)` | `scale(0.985) → scale(1.0)` |
| **右键菜单/浮层出现** | `150ms` | `cubic-bezier(0.16, 1, 0.3, 1)` | `opacity: 0 → 1; scale: 0.97 → 1` |
| **设置面板淡入** | `180ms` | `cubic-bezier(0.16, 1, 0.3, 1)` | 遮罩层与窗体平滑浮现 |
| **热键脉冲录制** | `1200ms` (循环) | `ease-in-out` | 红色光晕呼吸扩散动画 |
